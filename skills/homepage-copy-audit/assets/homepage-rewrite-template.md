**Recommended section sequence:**
1. **Hero** — What it is, who it's for, entry CTA
2. **Problem** — Agitate the pain in buyer language
3. **Solution** — What you do and how (3-step process or service description)
4. **Proof** — Case study result or key metrics (above the fold or just below)
5. **Offer** — Entry-point offer with specific deliverable and CTA
6. **Why us** — Differentiation, team, methodology

8. **FAQ** — Address top 4–5 objections explicitly
9. **Final CTA** — Repeat primary CTA with urgency or offer reinforcement

## Problem section (if missing or weak)

The problem section makes the buyer feel seen before you talk about solutions.

**Recommended approach — "3 pains" format:**
```
Most [ICP role]s we talk to face one of three problems:

1. [Specific pain 1 in buyer's language]
2. [Specific pain 2]
3. [Specific pain 3]

If this sounds familiar, you're in the right place.
```

**Alternative — "The cost of doing nothing" approach:**
```
Every month [ICP] teams continue doing [manual process], they [specific cost: time/errors/opportunity].
The tools to fix this exist. The problem is implementation.
```

## Proof blocks

### Proof block type 1: Case study summary

```
[Client name or "A mid-market logistics company in [city]"]
Challenge: [1 sentence — specific pain]
Result: [Specific metric] in [timeframe]
[Optional: 1-sentence client quote — attributed with name, title, company]
```

### Proof block type 2: Outcome stat

```
[Number]+ [outcome metric]
across [client count / geography / vertical]
```

### Proof block type 3: Client quote (specific)

```
"[Specific outcome or experience — not generic praise]"
— [Full name], [Title], [Company]
```

**Note on proof:** Generic testimonials ("Great team, highly recommended!") without name, title, company, and specific outcome are worse than no testimonials. Remove them and replace with the case study format above.

## Use case cards

Use case cards help buyers self-identify by showing concrete examples of who this is for.

**Card format:**
```
[Role/Persona Icon or label]
[Company type/size]

"[Problem they had in 1 sentence]"

→ [What was built/delivered]
→ [Specific result in buyer's language]
```

**Recommended use cases for B2B AI companies:**

**Card A — Operations team:**
```
Operations Manager
100–500 person manufacturing company

"Manual invoice processing was eating 40 hours/week across our team."

→ AI agent handling 85% of invoice matching automatically
→ Team freed up to focus on exceptions only
→ Result: 73% time reduction, 0 additional headcount
```

**Card B — Data/reporting:**
```
Director of Finance
Regional company, 200 employees

"Monthly reports took 3 days and were always late."

→ Automated report generation from existing data sources
→ Reports delivered every Monday at 6am, no human touch
→ Result: 40 hours/month reclaimed, zero errors
```

**Card C — Customer service:**
```
Head of Customer Experience
E-commerce company, 500 orders/day

"Support tickets were backlogged by 3 days during peak season."

→ WhatsApp AI assistant handling 70% of tier-1 queries
→ Human agents escalated for complex cases only
→ Result: Response time from 3 days to under 2 hours
```

## FAQ objections section

Address the 4–5 highest-frequency objections here explicitly. This is not a "nice to have" — unanswered objections are silent conversion killers.

**FAQ format:**

**Q: [Exact objection phrased as the buyer would ask it]**
A: [Direct answer — no fluff. 2–4 sentences maximum.]

**Recommended FAQs for B2B AI companies:**

**Q: What happens after the project ends? Will we be able to maintain it ourselves?**
A: [Answer honestly — if this is a differentiator, own it. If it's not yet true, fix the offer first.]

**Q: Our data is sensitive. Is it safe to use AI with our business information?**
A: [Address data privacy, model options, on-premise if applicable]

**Q: We tried AI tools before and they didn't work. Why would this be different?**
A: [Distinguish DIY tool adoption from structured implementation with methodology]

**Q: How long does it take to see results?**
A: [Specific timeframe. "It depends" is not an answer.]

**Q: What does this cost?**
A: [Either give a range or explain how pricing works — "contact for pricing" with no context is a conversion killer]
