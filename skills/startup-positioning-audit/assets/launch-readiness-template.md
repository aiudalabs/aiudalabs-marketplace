## ANALYTICS AND EVENT TRACKING CHECKLIST

_Set up before launch. You cannot optimize what you don't measure._

### Page-level tracking
- [ ] Google Analytics 4 (or Plausible/Fathom) installed
- [ ] Homepage pageview tracked
- [ ] Time on page tracked
- [ ] Scroll depth tracked (especially: do visitors reach proof section? FAQ? Footer CTA?)
- [ ] Bounce rate baseline established

### CTA and conversion tracking
- [ ] Primary CTA click tracked as an event
- [ ] Secondary CTA click tracked
- [ ] Form submission tracked (if form exists)
- [ ] Calendar booking tracked (Calendly webhook or GA4 event)
- [ ] "Thank you" page or confirmation tracked as goal

### Traffic source tracking
- [ ] UTM parameters set up for all outbound campaigns (LinkedIn, email, ads)
- [ ] Referral source tracking enabled
- [ ] Source/medium/campaign captured for every lead

### Lead tracking
- [ ] CRM or spreadsheet to log every inbound lead with source
- [ ] Discovery call booking tracked back to traffic source
- [ ] Lead-to-discovery rate tracked

### Session quality
- [ ] Heatmap tool installed (Hotjar, Microsoft Clarity — free)
- [ ] Session recordings enabled for first 100 visitors
- [ ] Click map on hero CTA

## CONVERSION TRACKING CHECKLIST

_Track the full funnel from visitor to signed client._

| Stage | Metric | Tool | Tracked? |
|-------|--------|------|---------|
| Visitor → CTA click | CTA click rate | GA4 / Plausible | [ ] |
| Visitor → Lead | Lead conversion rate | CRM + GA4 | [ ] |
| Lead → Discovery call | Show rate | Calendar / CRM | [ ] |
| Discovery → Proposal | Qualification rate | CRM | [ ] |
| Proposal → Signed | Close rate | CRM | [ ] |
| Signed → Case study | Proof generation rate | Internal | [ ] |

**Target baseline metrics for launch:**
- Homepage CTA click rate: >3%
- Lead form/booking conversion: >1%
- Discovery call show rate: >75%
- Proposal-to-close rate: >30% (for qualified leads)

**Red flags to watch in first 30 days:**
- CTA click rate <1%: Hero copy is failing; test alternate headline immediately
- Zero organic inbound in first 30 days: SEO/content not yet active — rely on outbound
- High bounce rate (>80%): Homepage is not resonating with traffic source
- Low scroll depth (visitors not reaching proof section): Message hierarchy issue above the fold

## 90-DAY POST-LAUNCH ROADMAP

| Phase | Timeline | Goal | Key actions |
|-------|----------|------|-------------|
| Foundation | Week 1–2 | Fix blocking issues, establish baseline | Fix must-fix issues, install analytics, first outbound |
| Early signal | Week 3–6 | Get first 3 discovery calls | Outbound sequence, LinkedIn content, first experiment |
| Validate | Week 7–10 | Close first 2 clients | Iterate on offer/CTA based on objections heard in calls |
| Optimize | Week 11–12 | Optimize homepage based on data | Apply learnings, build case study from first client |
