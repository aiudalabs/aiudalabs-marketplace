# Scoring Rubric

Use this rubric to score the startup across 12 dimensions on a 1–5 scale. Be honest. A 3 is not a passing grade — it means the dimension needs significant work. Reserve 4–5 for genuinely strong execution.

Apply each score based on what the homepage and available materials communicate to a first-time visitor who knows nothing about the company.

---

## Scoring scale

| Score | Meaning |
|-------|---------|
| **1** | Absent, broken, or actively harmful to conversion |
| **2** | Present but weak, vague, or unconvincing |
| **3** | Functional but generic; would not differentiate from competitors |
| **4** | Clear, specific, and effective; builds real trust or conviction |
| **5** | Exceptional; would be cited as a benchmark in the category |

---

## Dimension 1: Category clarity

**What it measures:** Can a first-time visitor immediately place this company in a mental category?

| Score | Description |
|-------|-------------|
| 1 | No category discernible; visitor has no idea what this company does |
| 2 | Category implied but not stated; requires reading multiple sections |
| 3 | Category is stated but generic ("AI solutions for business") |
| 4 | Category is specific and credible ("AI implementation agency for mid-market logistics") |
| 5 | Category is distinctive and owns a unique position the visitor has never seen claimed exactly this way |

---

## Dimension 2: ICP clarity

**What it measures:** Does the ideal customer profile know this is for them within 10 seconds?

| Score | Description |
|-------|-------------|
| 1 | No named ICP; "any company" language throughout |
| 2 | ICP implied by service category but never named |
| 3 | ICP is named (e.g., "B2B companies") but not specific enough to self-identify |
| 4 | ICP is named with specific criteria (role, size, vertical, geography) |
| 5 | ICP is named and there is language/use cases that make a non-ICP self-disqualify |

---

## Dimension 3: Pain clarity

**What it measures:** Is the buyer's main pain named explicitly in the buyer's own language?

| Score | Description |
|-------|-------------|
| 1 | Pain never named; site goes straight to solution |
| 2 | Pain implied through solution description |
| 3 | Pain named but abstract ("operational inefficiency") |
| 4 | Pain named specifically in buyer language ("your team spends 20 hours/week on manual data entry") |
| 5 | Pain is vivid, urgent, and specific; buyer feels recognized immediately |

---

## Dimension 4: Value proposition

**What it measures:** Is there a clear, credible, specific promise of what the buyer gets?

| Score | Description |
|-------|-------------|
| 1 | No value proposition; site describes services without outcomes |
| 2 | Vague value proposition ("We help you work smarter with AI") |
| 3 | Value proposition present but not differentiated from competitors |
| 4 | Value proposition is specific with a named outcome, timeframe, or metric |
| 5 | Value proposition is memorable, differentiated, and hard for a competitor to copy |

---

## Dimension 5: Differentiation

**What it measures:** Is there a specific reason to choose this company over alternatives?

| Score | Description |
|-------|-------------|
| 1 | No differentiation; could be any competitor's homepage |
| 2 | Weak differentiation ("we care more", "local team") |
| 3 | Differentiation present but could be copied easily |
| 4 | Differentiation is specific and verifiable ("only firm in X with Y") |
| 5 | Differentiation is genuinely unique, defensible, and prominently featured |

---

## Dimension 6: Credibility

**What it measures:** Would a skeptical buyer trust this company enough to start a conversation?

| Score | Description |
|-------|-------------|
| 1 | No trust signals at all; could be a scam or day-old company |
| 2 | Basic presence (team names, location) but no proof of delivery |
| 3 | Some social proof (testimonials, logos) but generic or unverifiable |
| 4 | Specific, attributed social proof with outcomes; visible team with relevant credentials |
| 5 | Multiple forms of specific proof; named case studies with metrics; credibility is a competitive advantage |

---

## Dimension 7: Offer clarity

**What it measures:** Does the buyer know what they're actually buying and what the first step looks like?

| Score | Description |
|-------|-------------|
| 1 | No offer described; just "Contact us" |
| 2 | Service categories listed but no specific offer or entry point |
| 3 | Offer exists but is vague ("custom solutions") |
| 4 | Offer is named with scope, deliverable, or timeframe |
| 5 | Offer is productized with clear deliverables, price signal, and TTV; buyer can make a decision without a call |

---

## Dimension 8: CTA strength

**What it measures:** Does the call to action clearly tell the buyer what to do and what happens next?

| Score | Description |
|-------|-------------|
| 1 | No CTA visible above the fold |
| 2 | Generic CTA ("Contact Us", "Learn More") |
| 3 | Slightly better CTA but still vague about what happens next |
| 4 | CTA names the action and sets expectations ("Book a Free 30-Min AI Audit") |
| 5 | CTA is compelling, frictionless, and creates urgency or clear value; buyer eagerly wants to click |

---

## Dimension 9: Proof strength

**What it measures:** How strong and specific is the evidence that this company delivers results?

| Score | Description |
|-------|-------------|
| 1 | No proof whatsoever |
| 2 | Generic claims ("hundreds of clients", "industry experts") |
| 3 | Proof present but vague (logos without context, testimonials without outcomes) |
| 4 | Specific proof with named clients/outcomes; at least 1 case study with metrics |
| 5 | Multiple specific case studies with quantified outcomes; proof is above the fold and undeniable |

---

## Dimension 10: Conversion readiness

**What it measures:** Is the homepage set up to convert a qualified buyer who lands on it today?

| Score | Description |
|-------|-------------|
| 1 | No path to conversion; visitor has no idea what to do |
| 2 | A conversion path exists but has 3+ friction points |
| 3 | Conversion path is there but requires significant effort from buyer |
| 4 | Clear, low-friction conversion path with a compelling offer |
| 5 | Frictionless conversion: one clear CTA, compelling offer, zero obstacles to starting |

---

## Dimension 11: Traction potential

**What it measures:** Based on the positioning, offer, and ICP, how likely is this company to generate leads within 90 days?

| Score | Description |
|-------|-------------|
| 1 | No clear path to traction; ICP and channel are both unclear |
| 2 | One plausible channel but the offer won't convert at scale |
| 3 | Viable positioning but traction will require significant iteration on offer or channel |
| 4 | Strong positioning with a clear offer that matches a channel; traction likely within 90 days |
| 5 | Exceptional positioning + offer + channel fit; buyer demand clearly exists and is accessible |

---

## Dimension 12: Launch readiness

**What it measures:** Is this company ready to launch now, or does it need major work first?

| Score | Description |
|-------|-------------|
| 1 | Not ready to launch; fundamental positioning, credibility, or offer gaps must be fixed first |
| 2 | Could launch but will generate very few leads without significant changes |
| 3 | Launchable but will underperform; 3–5 clear improvements needed before launch to avoid waste |
| 4 | Ready to launch; 1–2 quick improvements recommended but not blocking |
| 5 | Ready to launch immediately; positioning, offer, and credibility are strong; no major gaps |
