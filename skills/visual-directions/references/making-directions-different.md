# Making directions different

Three directions are useful only if choosing between them teaches something. That requires each to commit to a character.

## Start from a feeling

Write each direction as a sentence a non-designer could repeat:

- "A confident studio: heavy type, one hot color, a dark panel that feels like a tool."
- "A magazine about work: large serif headlines, lots of air, photographs of real sessions."
- "A poster: full-bleed color blocks and type big enough to read from across the room."

If two sentences could describe the same page, merge them and find another.

## Vary the big levers

Pick a different setting on at least three of these for each direction:

| Lever | Range |
| --- | --- |
| Who leads | Type leads · image leads · color leads · data leads |
| Headline voice | Heavy sans · elegant serif · condensed · mono · mixed with an accent face |
| Color behavior | A spot of color · color as whole sections · two colors in tension · nearly monochrome |
| Surface | Flat and printed · layered with shadow and depth · textured |
| Shape | Sharp and gridded · soft and rounded · mixed on purpose |
| Density | Sparse, one idea per screen · rich, lots to explore |
| Light and dark | All light · all dark · alternating bands · one dark object on a light page |
| Energy | Calm · lively · loud |

Changing only the hue, or only the font, produces a variant, not a direction.

## Give each one risk

Each direction should make one choice that could be wrong: a very large headline, a section in solid brand color, an unexpected typeface, an asymmetric layout. The risk is what people respond to. A direction with no risk is where blandness comes from.

Spend the boldness in one place per direction and keep the rest quiet, so the page still reads.

## Keep what must not vary

Hold these constant so the comparison is fair:

- the same real content, in the same order
- the brand name and, unless the logo is part of the question, the same logo
- the same page sections

## Warmth and expression

Rigor and plainness are easy for a system to produce and easy to justify, and they drift toward dull. Check each direction for:

- a source of warmth: a color, a human image, a rounded form, a serif, a line of personal copy
- a moment of contrast: dark against light, big against small, heavy against thin
- something to remember after closing the tab

If a direction has none of these, it is not finished.

## Common ways directions fail

| Failure | What it looks like |
| --- | --- |
| Three variants | Same layout and type, different accent color |
| The decoy | One good direction and two deliberately weak ones |
| The audit result | Every choice is defensible and nothing is attractive |
| Different for its own sake | A direction that avoids everything the category does and loses what suited the brand |
| Filler content | Placeholder copy that hides how the real headline would sit |
| No baseline | The current identity is missing from the comparison |
