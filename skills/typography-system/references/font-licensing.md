# Font licensing

A font is software, and its license decides where the brand may use it. Checking this is part of choosing the font, not a task for later.

## The rule

For every font the brand will use, read the license at the font's own source and record three things in the type system document:

1. The license name and version
2. The URL where you read it
3. The uses the brand needs, each marked as allowed, not allowed or unclear

If you cannot read the license, say so. Do not write "free for commercial use" from memory.

## Uses to check

| Use | What to look for |
| --- | --- |
| Website (web font) | Web embedding allowed; any limit on page views or domains |
| Mobile or desktop app | App embedding allowed; often a separate license from web |
| Logo | Use in a logo or trademark allowed; some licenses restrict it or require an extended license |
| Documents and PDFs | Embedding in documents allowed |
| Print and merchandise | Commercial print allowed |
| Self-hosting | Allowed to serve the font files from your own server |
| Modification | Allowed to subset, convert or alter the font |
| Sharing with agencies and contractors | Whether each party needs its own license |

## SIL Open Font License

Many freely available fonts, including a large share of those distributed by Google Fonts, use the SIL Open Font License (OFL), version 1.1. Source: <https://openfontlicense.org/>.

What that site states about the OFL:

- Fonts under it can be used in books, posters, artwork, logos and on websites.
- Acknowledgement is not required for such use.
- Reserved Font Names apply to modified versions: a modified font may not use a name the author has reserved.

Read the full license text for anything beyond these points, such as redistribution or selling the font files. Not every font on a free font site uses the OFL; some use the Apache License or the Ubuntu Font License. Check the specific font.

## Commercial fonts

Commercial licenses differ by foundry. Expect separate licenses for desktop, web and app use, often priced by number of users, page views or app installs. Before recommending a commercial font:

- confirm the user's budget allows paid fonts
- link to the foundry's license page
- list which license types the brand's uses require

Never suggest obtaining a commercial font from anywhere other than the foundry or an authorized reseller.

## System fonts

Fonts that ship with an operating system are licensed for use on that system. They can be named in a CSS fallback stack, because that asks the reader's device to use its own copy. They generally cannot be bundled, self-hosted or embedded in an app for other platforms.
